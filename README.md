# lazylogcat

A TUI for viewing Android logcat logs.

## Prerequisites

- Go 1.24 or higher
- `adb` (Android Debug Bridge) installed and in PATH

## Installation

```bash
go install github.com/parfenovvs/lazylogcat@latest
```

## Usage

```bash
# Launch the TUI
lazylogcat

# Enable debug logging
lazylogcat --debug
```
